# TP 4 : carnet de notes en mode menu

Programme C++23 : menu pour ajouter, afficher, modifier, supprimer, trier les notes,
calculer des statistiques et appliquer un bonus. Tout le code, sauf main, est dans
l'espace de noms carnet.

## Compilation

    g++ -std=c++23 -Wall -Wextra -Wpedantic -Wshadow -Wconversion -g -O0 tp4.cpp -o tp4

## Exécution

    ./tp4
